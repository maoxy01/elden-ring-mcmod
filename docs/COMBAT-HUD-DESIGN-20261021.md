# 战斗 HUD 布局

按用户 2026-10-21 草图及补充确认：右侧是饥饿与蓝条，左上是赐福地图入口。握姿由用户自行修改，本轮只处理战斗 UI。

## 位置与行为

- 左上：赐福地图的按键入口提示，读取已有 JourneyMap 全屏地图的真实绑定；改键后同步显示。未安装地图时明确显示“地图未启用”，未绑定则提示绑定；不伪造小地图，不新增地图模组，不另抢占按键。
- 顶部居中：沿用现有原版 Boss 血条及实体同步。
- 左下：原版生命、护甲及现有韧性显示。
- 右下：原版饥饿图标；FP 蓝条在其上方。氧气和坐骑生命仍按原版堆叠计数工作，蓝条随右侧堆叠上移。
- 快捷栏上方原经验条位置：R 战斗模式开启时绘制同步体力，复用原版经验条背景和绿色填充；关闭后恢复经验条及等级。只取消显示层，不写玩家 experienceProgress、experienceLevel 或总经验。
- 骑乘：体力占经验条位置，原版跳跃蓄力额外占上一行；生命/饥饿等堆叠为其上移 8 GUI 像素。
- 临时物品名称：沿用原版字体、内容和倒计时，只在战斗模式下必要时上移，避开 FP 标签。
- 普通界面不再堆放重复 HP/体力条、动作编号、网络序列、锁定实体编号和“上次战技”调试文字。F1、旁观、离线均不绘制战斗 HUD。

“战斗时”本轮采用项目已有的 R 战斗模式，不引入额外战斗状态计时器。地图旅行是否允许仍由现有服务端规则判断，HUD 不绕过战斗旅行限制。

## 复用与修改范围

复用了当前精确版本 Minecraft 1.21.1 / NeoForge 21.1.219 的 GUI 分层事件、经验与跳跃条 Sprite、原版状态栈和已有 JourneyMap 按键；检查了本机官方源码中的 Gui、VanillaGuiLayers、RenderGuiLayerEvent 和 GuiLayerManager。未重造经验或地图系统，未增加网络协议。

运行实现：`src/main/java/com/dsh/eldencombat/client/CombatHud.java`、`CombatHudLayout.java`；界面文案位于 zh_cn/en_us。布局预览可切换战斗/探索和步行/水下/骑乘，属于布局示意，非游戏截图。
