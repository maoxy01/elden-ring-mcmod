# 用户反馈修订：全装备手持偏小、普通装备质量不足

> 2026-10-13 最新用户确认：转向原版MC风格2D像素装备并优先复用现成模组。当前停止新增3D批次，已选旧大剑/特大剑与精修成果保留历史备份；不继续按本文33件全部重制。执行 [复用方案](REUSE-FIRST-DEVELOPMENT-PLAN-20261013.md)。手持尺寸、实际握柄、不同类别辨识度仍是新方案验收要求，旧3D场景证据不等同新2D场景通过。

用户明确反馈：所有武器在游戏手持画面偏小；八件追忆比较精美，其余武器制作质量不足。本工单调整当前优先级，最终尺寸与质量以游戏手持验收为准。

## 最新剑型要求与握持缺陷

后续用户在美术对话明确选择：“特大剑和大剑用旧版”。当前资产基线因此为旧版 great_sword / colossal_sword、新版 straight_sword。美术恢复这两件源/运行资产与生成策略，保留新版试稿用于对照；重算比例与柄区哈希。两件形状按用户选择保留，握持/尺寸校正继续，其他装备精修继续。不得用此前批量精修计划重新覆盖用户选择。

用户补充：剑的制作参考原版钻石剑，具有锯齿边缘；当前手没有握住剑把，而是握到空气。此处锯齿首先按钻石剑的像素阶梯外轮廓理解，不擅自改成带锯齿刀齿的现实锯条。

美术在六代表款中的直剑/大剑/特大剑优先落实阶梯刃缘、收尖与独立护手/剑柄，以实际钻石剑材质和模型作对照。需要提供新版正侧面和游戏手持对照，保持不同剑种轮廓差异。

握空气作为 P0 缺陷由战斗检查完整矩阵链，美术提供实际柄部中心/握持区段与源原点数据。不能只凭原点为零或浏览器夹具手柄对齐判定通过。缩放应围绕实际手握点，不把剑柄随着尺寸调整挪出手掌。

验收使用当前构建的真实玩家：原版钻石剑与三件新版剑同机位，第一/第三人称、左右手、标准/细臂分别取证；手掌包住柄部，护手位于手前，剑身不穿掌，攻击/防御姿态中不脱手。记录实际 JAR/资源哈希；先把握持固定，再比较三档尺寸。

1. 当前源码已出现逐件 heldScale 消费入口；先完成接入并确认最新构建实际加载比例资源。保留逐件差异、握点与独立 GUI 适配。

3. 配合美术提供当前/+15%/+30%三个实机尺寸候选。倍率是用户观感调校，独立记载；不能宣称新增倍率属于原作实测。

## 美术部门：33 件普通装备重新精修

用户不认可当前普通装备的质量；以追忆武器的结构完成度、贴图层次和辨识度为参照提高整批质量。

首批代表款：直剑、大剑、特大剑、矛、中盾、长弓。先做这六件的旧版/新版对照和实际手持截图，经审阅后推广其余 27 件；已有八件追忆以尺寸复核为主。

每件检查并实质改进：

- 轮廓：刃尖、肩线、护手或刀镡、柄与柄头具备明确设计；不同类别和具名参考具有独立形态。
- 结构：柄刃连接、金属套、镶嵌、缠柄、盾缘与背部支撑、弓臂与握把清晰连续；保留握持原点和既有活动结构契约。
- 材质：在游戏实际手持尺寸下，刃面、暗边、金属配件、木材/皮革可分辨；纹理密度和明暗组织与追忆资产协调。
- 源与游戏版：精细源与运行资产都更新；减面后仍保留关键轮廓和连接，不只增加源模型细节而让游戏继续显示旧版。
- 交付：可编辑源、模型/网格、贴图、预览、预算与哈希。复用现有资产管线并更新其源定义，保证重新生成不丢精修。

沿用用户已经确认的薄片与低饱和方向；尺寸变大后重新检查厚度、比例、握点和材质，不能仅放大来代替精修。具体原作比例校准继续逐件记录，不把暂定初值标成定稿。
