## 源码变化与边界

### 赐福

`GraceDiscovery` 将玩家已被 Waystones 确认激活的普通 `WaystoneTypes.WAYSTONE` 纳入赐福，不再依靠测试夹具提前登记。原生激活、已发现节点列表、实际方块交互和原生旅行 Pre 都接入此核对，避免首次发现后的短窗口漏掉战斗限制。传送板、共享石等不会被一并冒充普通赐福。删除节点会撤销登记；权限和玩家发现记录仍由 Waystones 判断，不把全局 UID 登记当作全员发现。

新休息默认恢复生命、FP、精力及现有药瓶次数，只清除映射的中毒/凋零，保留有益药水效果。精力使用装备加成后的容量。成功才同步和播放少量原版金色粒子/声音；被拒绝的休息不会先补资源。新包包含明确 FULL 配置；旧自定义配置中的 KEEP 在代码读取时仍受尊重。

不更改食物、经验、背包、世界时间、原版床重生点或普通生物生成。原作“普通敌人重置”“最后赐福复活”等行为尚未移植，不能通过全世界清怪/重刷来模拟。保留人类的非战斗时野外前往已发现赐福规则，不取消安全落点、权限、请求去重与原生异步校验。原生旅行费用/冷却管线仍保留，未宣称免费旅行已与原作完全一致。JourneyMap仍是可选地图显示，本轮未增加它。

### 护符

- `TalismanEffects` 在旧字段之外增加有作用范围的效果；旧自定义数据包字段与真实物品容器继续兼容。四件内置数据已使用新字段和系列。旧版数值单测保留为兼容样本，而非当前内置平衡。
- `TalismanCombatEvents` 在 NeoForge21.1.219 的 `LivingDamageEvent.Pre` 处理受伤倍率：护甲/药水减免之后、吸收之前，单次处理。删除玛尔基特调用处的重复护符乘数，避免双重减伤。PvP按伤害来源的玩家归属判断，包含正常带玩家所有者的箭。
- 物理类型由数据包 `data/eldencombat/tags/damage_type/talisman_physical.json` 明列，其他模组可追加。火焰、间接魔法及未分类来源不自动当物理；黄金波改走非物理来源。其余既有攻击仍依 Minecraft 当前伤害类型分类，尚未引入原作完整混合属性拆分。
- 战技倍率只进入项目战技的直接命中。第三方原生能力未因持有某把武器被擅自识别为项目战技；原生攻击、冷却和能力继续保留。要扩展第三方技能加成，需要提供可验证的技能命中来源，不能全局把普攻当战技。
- 力敏是派生值，不写回玩家投入属性。生命使用本项目独立 transient modifier，精力使用现有 `CombatState`；装备/卸除只夹紧容量，不补资源、不另造资源附件。登录、克隆、重载按真实容器刷新。
- 护符客户端快照已增加效果字段，网络协议由7升为8；客户端/服务端须使用同一新版。原有动作/旧翻滚编号未重排。Tooltip及赐福提示显示实际效果，不输出 Java 记录名。
