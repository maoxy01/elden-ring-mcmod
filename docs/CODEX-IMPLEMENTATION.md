## 已接入

- 玩家：读取实际皮肤、标准臂/细臂、用户开启的皮肤第二层；战斗时使用 17 骨骼/10 方块，非战斗、死亡、骑乘、游泳、滑翔、潜行等特殊原版姿态退回原版。保留披风等既有层，盔甲按分段骨架绘制，沿用原版材质、染色、纹饰和附魔管线。
- 装备：注册 `eldencombat:straight_sword`、`great_sword`、`shield`，配合原有 `test_flask`；创造模式战斗分类可领取，`/eldencombat testkit` 发自制装备。大剑双手握持使用离线烘焙旋转，防御/弹反恢复盾牌，翻滚隐藏装备，喝药只显示药瓶，不改背包内容。
- 视角：第三人称附着实际手部插槽；第一人称复用动作骨架，采用独立缩放/偏移。玩家建模左右轴与 MC 主手约定在渲染、原版附着层及服务端采样处一致转换，不翻转皮肤 UV。
- 同步：协议版本 2，长整型世界 tick、动作变体、锁定的武器档位、臂型、主手、配置窗口、防御反馈与翻滚朝向同步给本人和正在追踪的玩家。换武器或主手取消攻击/蓄力，死亡、换世界与退出清理状态。
- 判伤：使用玩家骨架插槽和真实刀身轴，配置窗口映射到同一动画进度；上一/当前 tick 连续胶囊采样，隔墙 raycast、同序号对目标最多一次伤害。原来的近似 reach 不再叠加。匕首修正为装备本地轴，不取世界 AABB 最远角。
- 翻滚：先走服务端地形碰撞，再同步实际位置，避免被原版客户端移动包覆盖。Y 没有变化时保留原版垂直速度和视角；视觉 root Y 位移不驱动物理。
- 反馈：原版 Boss 红血条、盾防/弹反/破防/命中/喝药粒子、落地冲击、黄金武器细小窗口拖尾、死亡 40/44/48 tick 尘粒与身体淡出。全亮黄金件保持不透明；三张原创粒子贴图已进包，活粒子预算 160，重载后不会永久卡住。
- 音效：服务器按事件跨越区间和确认结果派发原版声音，脚步沿用原版避免双播；没有引用不存在的 OGG。原创音频仍待制作。
- 稳定性：修正混用服务器计数和世界 tick、黄金锤同名 head 面材质异常、未排序事件、取消包绕过序号检查、非有限方向参数、移除盾牌仍能格挡/弹反等问题。

## 资源与代码入口

自定义数据在 `assets/eldencombat/skeletons/player`、`skeletons/entity`；原版物品模型仅在 `models/item`，避免原版模型加载器扫描自定义 JSON。`syncArt` 的 `assetLayoutVersion` 是映射结构的任务输入，改目录后会正确重新同步。

骨架加载与共用采样：`PlayerAssets`、`AnimationClip`、`ClipTiming`、`SkeletonPose`、`SkinLayout`。服务端：`ServerCombat`、`HitResolver`、`CombatEffects`。客户端：`CombatPlayerModel`、`CombatArmorModel`、`CombatHeldItemLayer`、`CombatHandRenderer`、`PlayerMeshRenderer`、`EquipmentRenderer`、`PlayerVisual`。玩家渲染器模型字段通过客户端专用 Mixin 接入，不在服务端加载渲染类。

玛尔基特源资产未改：19 骨骼、38 方块、8 动作，尾巴恰好三骨三块 `tail_01 -> tail_02 -> tail_03`。没有处决、配对终结或专门跳跃攻击，原版跳跃及普通空中攻击保留。

## 验收

共享自检扩充到 420 项，覆盖全部臂型/武器/动作的半 tick 有限矩阵、刀轴长度、左右镜像、皮肤/第二层 UV、原版六面朝向、双手握持、视觉根无 X/Z 物理位移、配置重定时、乱序/循环事件及高速扫掠。JUnit 只有一个入口测试，入口内执行这些共享检查，不把检查数冒称为 420 个 JUnit 方法。

开发客户端在隔离存档中实际启动，13 组截图涵盖皮肤、盔甲防御、直剑轻击/满蓄力、翻滚、弹反、喝药、双手大剑、左手大剑、第一人称和原版退回。截图路径：`build/clientSmoke/screenshots/`。这不是浏览器效果图。

真实网络请求测试与独立服务端启动结果以对应日志中的 `CLIENT_NETWORK_PASS`、`SERVER_SMOKE_PASS` 和 `[etest]` 为准。测试用的直接设定姿态只用于渲染场景；网络验收另行发送实际 C2S 请求，不以假姿态证明规则成立。

已实测的网络流程：切换战斗、绑定武器的轻击、旧取消包拒绝、真实刀身命中一次、新取消包接受、盾防开始/结束、喝药第 18 tick 前后、满蓄力释放、翻滚位移/高度/窗口清理、换武器取消蓄力。另测撞墙停止及空中翻滚不冻结下落。原版位置同步 API 的参数仍是绝对目标，relative 标志只影响发出的包；服务端和客户端都校验高度，防止只看动作状态误判移动成功。

## 仍需验收

单人试玩调数值；长时间游玩、低 TPS、多人延迟和其他玩家模型/渲染模组共存；潜行等原版退回姿态与战斗刀身的视觉差异；第一人称快速连续动作的舒适度。当前为玛尔基特战斗原型，不是完整法环内容复刻。

原创音频未制作；粒子 JSON 是随包设计规格，当前 Java 使用对应首版参数，暂不是通用热加载特效编辑器。玩家死亡使用原版生命周期，不强行延长死亡计时播放 40 tick 草稿。没有为本批增加地图、符文、赐福、属性体系或更多 Boss。
