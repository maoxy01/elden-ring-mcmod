# 战技动作：手臂幅度控制 70% 修订

根据用户“手臂幅度减少30%”，以未收幅的原始转换姿态为基准，将左右臂独立幅度控制从 0.85 调整为 **0.70**。不是在上一版上再乘 0.7。腰部设置、头腿、整体朝向、源骨架对照和 1.3 倍播放速度保留。

最新版：[工程说明与八技入口](../local-research/elden-source-motion-20261021-arm70/README.md)。[黄金波动工程](../local-research/elden-source-motion-20261021-arm70/projects/wave_of_gold.bbmodel)。上一版目录保留，修订不覆盖旧工程或人工握姿。

沿用原转换方案的连续四元数向量缩放：`q' = normalize([gain*q.xyz, q.w])`，左右臂 `gain=0.70`，头腿仍为 `0.85`。该值是幅度控制增益，普通摆动收小；不等于每个大角度都机械乘 0.7，完整翻转仍保持连续。

已生成八个 Blockbench 工程、十五段动作。离线逐段核对：手臂实际姿态角距离不大于上一版；其变化符合上述增益公式；非手臂四元数轨道、人物整体朝向、根运动参考及全部时间点与上一版完全一致。腰部仍为 0.6 增益，前后弯/侧倾各限 15°、局部扭腰限 20°。

已在 Blockbench 5.2.2 原生加载、核对、编译八个工程，重新打开黄金波动检查插值。共核对 1,260 个六关节姿态和 75 个帧间插值时刻，包含独立父组朝向与原始关节点检查。原有五个标签页（包括上一版黄金波动）保持原名称、UUID 和保存状态。
