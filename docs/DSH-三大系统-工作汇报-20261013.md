## 七、经验与风险（给下一轮）

1. **`BUILD SUCCESSFUL` / 退出码 0 不是通过**：夹具失败只写 `*_FAIL`，gradle 照样 0。
   判定必须查 `*_PASS` / `*_COMPLETE` 且确认无 `*_FAIL`。本轮 `-PashSmoke` 就是活例。
2. **夹具的 `step` 走客户端 tick，游戏逻辑走服务端 tick**：任何"到第 N 步应该已经发生"的断言
   都会周期性误报。已有三处因此改法（施放收招、菜单重开、飞行菜单），本轮又修两处。
   新写断言请一律改成"轮询 + 超时上限"。
3. **夹具复用同一个世界**：上一次运行留下的血量/位置/解锁会污染下一次断言。
   赐福夹具已在开局显式复位（死亡也走原版重生路径），收尾补满血 + 清摔落距离再存盘。
   **不要删 `build/gracePrototypeClient/saves/grace-prototype/playerdata`**：赐福节点授权断言依赖它。
4. 并行写 `build/` 会互相踩：gradle 运行必须串行。
