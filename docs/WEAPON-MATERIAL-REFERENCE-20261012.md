# 武器材质修订：薄片结构，法环质感

## 这轮决定

用户要求参考 MC 原版的薄片像素结构，但反馈上一版质感太卡通。
本轮不改变这个结构方向：1 模型单位像素，1/16 格厚度；重新设计基础配色与正反面明暗。
只修改武器、盾牌、圣杯瓶的美术资源及资源验证工具。玩家、Boss、战技动作和战斗参数不改。

## 美术调整

| 对象 | 本轮采用的方向 |
| --- | --- |
| 普通钢制武器 | 灰钢主面、深色脊线、窄刃口亮色，不再整片亮青 |
| 护手和包柄 | 降饱和旧铜、深色皮革；减少统一亮黄色装饰 |
| 神躯化剑、义手刀 | 旧金与暗金的层次，保留武器轮廓 |
| 玛莉卡石槌 | 灰石主体、压低亮度的金色裂纹 |
| 黑剑 | 黑铁与灰金属护手；静态武器不涂满鲜红发光色 |
| 亵渎圣剑 | 暗血、锈红与肉质暗面，减少鲜红塑料感 |
| 碎星大剑 | 黑铁与低亮度金纹，保留成对预览 |
| 蒙格温圣矛 | 旧铜与深色长柄 |
| 蒙葛特咒剑 | 大块紫、橄榄绿和灰钢综合色，取消满刃亮蓝 |
| 盾牌 | 连续盾面、深色外框与局部纹章，保留少量厚度 |

正反面采用方向性三档明暗；磨损仅放在边缘，形成稀疏的小片区，不撒随机噪点。
侧壁使用暗色，图集 UV 内缩半个纹素，避免边界采到邻近色块。
这些都是像素基础色与烘焙明暗，不是新加入的 PBR、法线贴图或动态金属反射。

## 资产与交接

- 33 件主要类型武器/盾牌：`art/weapons/`。
- 8 件追忆武器：`art/remembrance-game/`。
- 4 份旧版装备资产：`art/player/` 中直剑、大剑、盾牌、圣杯瓶。
- 共 45 份模型文件，其中 3 份为旧装备别名；不能把它说成 45 件独立新物品。
- 高细节源 `art/remembrance/` 保留，不替换玩家皮肤或 Boss 模型。
- 原模型备份：`art/backups/flat-equipment-before-20261012/`。
- 本轮材质修改前备份：`art/backups/flat-equipment-v2-before-materials-20261012/`。
- 两份备份均有 SHA-256 清单；验证工具检查备份内容、未修改的玩家模型及动画文件。
- 扁平化重建入口：`node art/tooling/flatten-equipment.mjs`，固定从原模型备份生成。
- 材质规则：`art/tooling/equipment-material-style.mjs`。
- 本轮报告：`art/flat-equipment-report.json`。

运行模型仍使用原物品 ID、单位比例与握持原点。普通武器的预烘焙网格已纳入 `syncArt`。
不要通过改物品 ID、战斗范围、FP、战技参数来补偿美术上的厚度变化。
图鉴截图及本地参考目录不进入 JAR。

## 验证与限制

材质规则测试 4 项通过；45 份资产通过结构、UV、导出一致性与备份完整性检查。
桌面 1440x1024、手机 390x844 预览验证通过；共检查 135 次正面、侧面、背面渲染，无空白或裁切。
Java 回归测试覆盖 41 件运行武器的模型与网格加载路径，以及 4 份旧装备。
最终 Gradle 构建成功。JAR 内容复查确认 41 件运行武器均为材质修订 3，引用网格完整，无备份、网页预览和 Blockbench 文件。
未声称已完成玩家的游戏内视觉验收，也未进行 FPS 对比。

预览：`art/weapons/preview.html`、`art/remembrance-game/preview.html`、`art/player/equipment-flat-preview.html`。
审查截图和机器可读结果：`art/flat-equipment-qa/`。
