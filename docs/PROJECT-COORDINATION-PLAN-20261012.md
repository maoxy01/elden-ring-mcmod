## 3. 需要先纠正的计划错误

1. 初始打包链错误要求 Epic Fight、空客户端 mixin 和旧 EF 能力资源。战斗已改为七模组锁表与实际 PlayerModelPoseMixin 校验；源码修复已见，真实打包与新实例导入仍待验收。
2. 美术任务包对 placeholder 的结论证据不足。共用入口可以承载每件独立 3D 模型；禁止仅为消除 parent 名字而改成 generated，导致手持退化成平面。
3. 历史战技时序建议尚未完整落地，而且当前黄金波动收招为 5 tick，不是旧文档统一写的 10 tick。收口必须依据当前参数表，不整表照抄旧数值。
4. 起手接受前的提示无法凭空预知。提示从服务端接受施放后启动；如果要延长可反应时间，应在状态机内显式安排，不复制“起手前 6 tick”表述。
5. 武器、VFX 的静态几何预算不等于 FPS 或 GPU 时间达标；源版减面比例也不等于帧率提升比例。

本轮统一状态：待执行 / 进行中 / 实现完成 / 自动检查通过 / 实机验收通过。报告至少写明：任务 ID、改动文件、实际命令与结果、证据路径、失败或跳过项、给另一部门的接口变动。没有实机证据就不写 shipped。
