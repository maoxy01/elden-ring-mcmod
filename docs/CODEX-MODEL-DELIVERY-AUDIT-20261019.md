## 结论

当前不能把“最新Blockbench工程”“full已选素材”“实际安装资源”视作同一版。上次安装核验只证明36个第三方文件与已构建项目JAR一致，没有充分核对项目JAR内的美术是否对应最新已选素材；这个交付缺口现已确认。

1. **已选五件漏接入**：曲剑、大曲剑、双头剑、玛莉卡石槌、蒙格温圣矛的15张full PNG与10月18日人类“都采用新版”的选版回执全部一致，但安装JAR中的对应15张PNG字节和RGBA像素均不同。28件94状态对照中仅79张full素材与安装JAR一致。构建输出与实际D:/PCL安装JAR均为 `bd4e648ea9866bfb77ff59204a92e2eeea802b57405e55d5a18f6d1a5984d769`，所以不是复制到了另一份JAR，而是产物美术快照落后于已选full。后续须按已选PNG、轮廓跨度和握点重新生成关联资源，不能只换一张贴图就宣称比例和握姿同步完成。
2. **独立咒剑与总工程分叉**：`blockbench-all-items-20261018/items/morgotts_cursed_sword.bbmodel` 现有95个元素；Git HEAD快照为84个。当前独立工程的3张内嵌贴图均与 `revisions/stars-morgott-r2/textures/` 的二次优化前备份像素相同，与当前总工程/94张候选导出PNG不相同，模型哈希也不符合候选manifest。不得按较新的修改时间直接把这份独立文件当作二次优化最新设计。所有文件保持原样，未回滚或覆盖。
3. **最新28件仍是另一层候选**：`blockbench-all-items-20261018/manifest.json` 登记28件、94张状态贴图，三项状态仍为 `humanAccepted=false / runtimeIntegrated=false / inGameAccepted=false`。94张候选PNG全部与full现行已选素材不同；总工程内嵌纹理与候选PNG的94项像素比较通过，27份独立工程与其一致，咒剑3张不一致。该批候选未因“模型文件存在”而自动接入游戏。本次未擅自替换已选资源。
