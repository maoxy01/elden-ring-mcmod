# GitHub 开发进度快照

日期：2026-10-14。当前工程：Minecraft 1.21.1、NeoForge 21.1.219、Java 21、Elden Combat 0.2.0。此快照记录开发状态，不是正式发布或完整验收声明。

## 当前方向与分工

保留原版生存、玩家动作与自由探索，装备转原版像素风2D，战技使用2D序列贴片。先复用已有方案，再补缺口。统筹负责计划和审查，美术负责源资产；战斗部门维护代码框架设计，DSH负责具体实现。用户当前主攻美术。

## 已有开发成果

- 八个追忆战技、FP、强化/质变、战灰绑定、护符容器及赐福保存/地图旅行已有实现。准确测试范围和遗留事项见各系统回执，不将单机夹具等同于多人或人工游玩验收。
- 八个追忆战技特效已有10组动画、160张透明帧；代码已有10条ready路由及真实atlas加载/绘制记录。完整视觉验收仍未完成，见 DSH-VFX-IMPLEMENTATION-CONTRACT-20261014.md。
- 赐福已有15项原创图标/空间贴片草案，地图已有接线；空间表现和UI仍需收尾。
- 装备共有42项：33类普通装备、8件追忆、1药瓶。完整映射表已建立，六类代表已交付自有精灵或合法完整依赖映射，尚未实机接入。其余36项已派美术续作，以上是已审阅基线，后续产物以其最新交接为准。
- 上传前复核部门状态：美术剩余36项、战斗装备2D接入设计两项后续任务均因账号额度限制中断，尚未交付。保留已写文件与派工要求，待额度恢复后接续，不将“已派发”记为完成。
- 58项既有材料/护符等物品资源继续复用。历史模型和选定旧大剑/特大剑仍保留本地，当前源文件纳入版本管理。

2. 装备运行接入：外部模型、逐件display与握柄参数，第一/第三人称、左右手及标准/纤细手臂验收。
3. 战技特效有效环绕夹具、辅助地块、地形障碍、缺图重载和全套观感收口。
4. 赐福/FP/UI统一、首个遗迹及奖励的最终集成。
5. 多人、光影/兼容、PCL新实例安装与完整人工游玩验收。

## 快照内容与排除项

版本管理包含当前源码、Gradle脚本、整合包配置/依赖锁、当前自有美术源与制作工具、计划和交接文档。缓存、build/dist、运行存档、node_modules及历史重复备份保留本地，不上传。研究用第三方JAR/PNG及含第三方素材的样板截图不纳入；保留来源、许可和哈希证据，运行依赖按官方渠道获取。六类预览中研究PNG需由本地已获取的精确依赖重建，云端仓库不会独立包含这些贴图。

构建依赖不随快照打包。本机 gradle.properties 使用 D:/JDK21 和127.0.0.1:7890代理，其他机器需按实际环境调整。上传动作不运行构建或游戏，不更新既有验收结论。
