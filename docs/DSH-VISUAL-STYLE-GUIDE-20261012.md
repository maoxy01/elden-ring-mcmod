# 视觉风格指南

> Codex 审查备注（2026-10-12）：本文件是方向参考，不是已由用户批准的硬约束。
> 当前实际运行资产是 1 模型单位像素、1/16 格薄片、128 像素武器图集，旧装备图集 64；2048 仅保留在高细节编辑源。
> 不恢复旧版密度/图集，不修改玩家和 Boss。60/30/10 不强制套用到黄金主题战技，命定之死的黑红双色和咒剑综合色也保留例外。
> 轴对齐与网格粒度约束建模静态局部坐标，不约束骨骼旋转、动画插值、世界变换和 billboard 的最终顶点。
> 光、雾、透明层并非零 GPU 成本；满亮度不等于真实光照或泛光。光影是否改写具体通道要实测，不能统一断言接管所有 Shader。
> 功能与验收口径以 `DSH-VFX-PIPELINE-SPEC-20261012.md` 的“当前有效契约”为准；以下保持原建议供追溯。

日期：2026-10-12。给 `D:/codexout/mcmod` 定统一的视觉调性，覆盖武器 / 敌人 / 特效 / 环境四层。

## 0. 核心矛盾

| | 视觉语言 |
| --- | --- |
| **Minecraft** | 体素、正交网格、低分辨率像素贴图、高对比、明度分层表达体积 |
| **艾尔登法环** | 写实 PBR 材质、体积雾、黄金高光、哥特式建筑、油画般的暗黑奇幻 |

这两套是**直接冲突**的。硬做写实会毁掉 MC 的调性（玩家一眼看出"这不是 MC"），硬守方块又会丢掉法环最值钱的东西——那种庄严、衰败、神圣感。

## 解决原则

> **模型层面忠于 MC，氛围层面向法环靠拢。**

具体说：**几何保持体素，把预算全部投到光、色、粒子、雾**。

理由见下一节——这是我认为整个风格决策里唯一重要的一条论证。

---

## 1. 关键论证：庄严感靠光，不靠多边形

拆一下"法环感"由什么构成，以及在 MC 里能不能做：

| 组成 | 依赖 | MC 可行性 |
| --- | --- | --- |
| **光线质感**（黄金树、逆光、丁达尔） | 体积光 + 泛光 + 雾 | ✅ MC 原生有雾；Iris 下体积光/泛光成熟 |
| **色彩关系**（金 / 暗红 / 灰石的三角对立） | 贴图与顶点色 | ✅ 完全可控，零成本 |
| **氛围**（雾气、尘埃、余烬飘浮） | 粒子与透明层 | ✅ 你们已有网格/贴片通道 |
| **剪影**（巨物、破败轮廓） | 模型外形，不靠细节 | ✅ 大体量低细节完全可行 |
| 材质细节（布料、皮肤、锈迹） | 高分辨率 PBR | ❌ 与 MC 调性冲突，**放弃** |
| 面部表情、手指动作 | 骨骼与形变 | ❌ MC 无骨骼动画，**放弃** |

**结论**：法环最值钱的三样东西——光、色、氛围——恰好都是 MC 渲染层能做的，而且**不消耗几何预算**。而它那些做不到的（精细材质、面部），恰恰是最不需要的。

所以正确的资源分配是：

| 维度 | 投放 |
| --- | --- |
| 模型精度 | **克制**，保持体素，细节做在剪影和分层结构 |
| 色彩 | **重投**，建立可编码的配色体系 |
| 特效（光/粒子/雾） | **重投**，这是氛围的主要载体 |
| 音效 | **重投**，魂系打击感的一半来自声音 |

> 反过来说：如果一个效果需要靠加几何精度才能"显得有分量"，说明色彩和光没做对。

## 2. 主推方案：暗黑奇幻方块风（Dark Fantasy Blocky）

一句话定义：

> **体素的形状，油画的颜色，光影的氛围。**

三条支柱：

### 支柱一：体素不可破

- 所有几何吸附到 1/16 方块网格（与你们模型单位一致）
- 允许分层、收尖、铆钉、镶嵌表达细节，**不允许斜面和非正交几何**
- 武器已有精细方块风格（分层刃面、护手、缠柄），这是对的，保持

### 支柱二：油画配色

法环的调色是**低明度、中低饱和打底，高饱和金色点缀**。这是它"庄严而不俗气"的原因。

**核心色板**（原创，不搬运法环资源；明度分三级以适配 MC 贴图的体积表达）：

| 语义 | 高光 | 中间调 | 暗部 | 用途 |
| --- | --- | --- | --- | --- |
| **黄金 Gold** | `#FFF0B8` | `#E8B84B` | `#8A6A1F` | 神圣、追忆、祝福、黄金系战技 |
| **暗红 Crimson** | `#D94452` | `#8B1E28` | `#3D0A10` | 血、腐败、献祭、咒血系 |
| **石灰 Stone** | `#9C9890` | `#6B6862` | `#33312E` | 建筑、环境、衰败背景 |
| **辉石 Glintstone** | `#9DB4FF` | `#4A6FD4` | `#1E2B58` | 魔力、法术、星海系 |
| **苍白骨 Bone** | `#F0ECDA` | `#D8D2BE` | `#8A8470` | 死亡、亡灵、枯败 |
| **黑曜 Obsidian** | `#5A5A66` | `#2A2A32` | `#121216` | 深渊、虚空、无光 |
| **火焰 Flame** | `#FFD08A` | `#E07B2A` | `#7A2E0C` | 火焰系、亵渎 |
| **闪电 Lightning** | `#E8F0FF` | `#7BA8E8` | `#2A3F6B` | 雷系、龙 |

**使用铁律 —— 60/30/10**：

```
60% 主色：石灰 / 苍白骨（低饱和打底，提供"历史感"）
30% 辅色：暗红 / 辉石 / 火焰（单一元素主题，不要混）
10% 点缀：黄金（高饱和，只在最关键处用）
```

**黄金用滥是这个风格最常见的死法。** 黄金之所以值钱，是因为它稀有。如果每件武器、每个特效都在发光，那它只是一个"黄色"，不再意味着神圣。

### 支柱三：光影氛围

- **不要投射真实动态光**（会改区块光照 → 触发 chunk 重建 → 帧率崩）
- **发光靠渲染时满亮度**：给该次绘制强制打包满亮度，只影响这一次绘制、不写世界数据。看起来在发光，零世界开销
- **氛围靠雾**：MC 原生雾承担大部分"距离感/神秘感"。区域间用不同雾色区分调性
- **尘埃与余烬**：少量常驻飘浮粒子，是性价比最高的"环境活着"信号

## 3. 体素密度契约（可量化的统一标准）

风格散架的头号原因是**不同资产的细节粒度不一致**——精细武器配上粗块敌人，割裂感立刻出现。

定义统一网格 `1 方块 = 16 单位`，规定每个层级的最小细节单元：

| 层级 | 最小细节单元 | 示例 | 现有资产 |
| --- | --- | --- | --- |
| **武器** | 2 单位（1/8 方块） | 刃面分层、护手、铆钉、镶嵌 | ✅ 已符合（2048 图集 + 逐面 UV） |
| **敌人 / BOSS** | 4 单位（1/4 方块） | 关节分块、体节、武器握持 | ✅ 粗块风格，符合 |
| **特效** | 2 单位 | 波面阶梯、方框分层、碎块 | ✅ 96 方块上限，符合 |
| **环境 / 建筑** | 8 单位（1/2 方块） | 柱式、拱、破口、砖缝 | ❌ 未做，按此标准 |
| **道具 / 消耗品** | 4 单位 | 瓶、铃珠、钥匙 | ❌ 未做，按此标准 |

**硬规则：相邻层级的细节粒度差不得超过 2 级。**
武器（2）到敌人（4）差 1 级，可接受。武器（2）到环境（8）差 2 级，是上限——环境不能再粗了，否则同屏会出现"精细剑砍豆腐块墙"。

## 3.1 分辨率契约

贴图分辨率同样要统一，否则会出现"远处建筑清晰、近处武器糊"：

| 类别 | 基准分辨率 | 说明 |
| --- | --- | --- |
| 武器 | 2048 图集（已定） | Hero 级，玩家天天看 |
| 敌人 / BOSS | 512–1024 | 中距离观看 |
| 特效 | 复用原版粒子图集 / 顶点色 | 零新增资源 |
| 环境 | 256–512 | 大面积重复，不需要高分辨率 |
| 道具 | 128–256 | |

## 4. 四层资产的一致性要求

### 4.1 武器层（已成型，保持）

- 精细方块：分层刃面与收尖、护手、缠柄、铆钉、金属配件、镶嵌、盾面纹章
- **不要退回"只改名字的同形模型"**——这一条项目文档里已经写了，非常对
- 握持原点统一 `[0,0,0]`，主长度轴 +Y，盾面 -Z / 盾背 +Z
- 左右手用插槽变换处理，**不可翻转贴图**

### 4.2 敌人 / BOSS 层（粗块，与武器形成对比）

项目的"粗块风格、简单关节、三节尾巴约束"是对的，**不需要跟着武器一起提高精度**。理由：

> 敌人是背景，武器是焦点。粗块敌人在视觉上把精细武器衬托出来——这是有效的层次策略，不是不一致。

前提是体素密度契约里两者只差 1 级（2 vs 4），不越界。

### 4.3 特效层（网格 + 贴片双通道）

- 主形状 = 立体网格（真三维）
- 刀光 = 相机朝向贴片（二维欺骗，但便宜）
- 元素靠颜色/形状编码，且**统一性优先于美术效果**
- 每个战技必须有"不看颜色也能认出"的形状签名

### 4.4 环境层（空白，风险最大）

这是唯一完全没做的层，也是风格最容易失控的地方。三条预防：

1. **先定雾色再建模**：每个区域先定雾的颜色与密度，建筑配色服从雾色
2. **建筑用有限模块**：设计 8–12 个结构模块（柱、拱、破口、台阶…），靠组合出变化，不逐栋建模
3. **严格遵守 60/30/10**：环境几乎全是主色（石灰），元素主题色只出现在特定区域

## 5. 材质与光照规范（MC 渲染层的能与不能）

### 5.1 贴图规则

| 做 | 不做 |
| --- | --- |
| 明确的高光 / 中间调 / 暗部三级明度 | 照片写实纹理 |
| 高对比、清晰的边缘 | 大幅渐变（MC 调性冲突） |
| 用明度表达体积 | 用法线/高光贴图堆细节 |
| 有限色板内的配色 | 无约束取色（会立刻破坏油画感） |

### 5.2 发光规则

| 做 | 不做 |
| --- | --- |
| 渲染时给该次绘制强制满亮度 | **真实动态光**（改区块光照 → chunk 重建） |
| 加性/透明混合的贴片模拟辉光 | 自定义 ShaderInstance 承载关键逻辑（Iris 下会被接管） |
| 发光信息编码在**贴图**里 | 发光信息编码在 **shader 逻辑**里 |

> 第三条是硬约束：装了 Iris 且开光影包时，自定义 shader 会被接管。**信息必须编码在贴图里，不能编码在 shader 逻辑里。**

### 5.3 氛围规则

| 参数 | 建议 |
| --- | --- |
| 雾 | 每个区域一个雾色，承担主要氛围 |
| 常驻飘浮粒子 | ≤ 12 个/区域，成本极低收益极高 |
| 天空 | 与区域雾色协调，不做复杂大气散射 |
| 后处理泛光 | 走光影包，不自研 |

## 6. 备选方案对比

如果你不认同主推方案，下面是完整的方向谱系和切换代价：

| 方案 | 定义 | 契合 MC | 法环感 | 工作量 | 评价 |
| --- | --- | --- | --- | --- | --- |
| **A. 暗黑奇幻方块风**（主推） | 体素形状 + 油画配色 + 光影氛围 | ★★★★★ | ★★★★☆ | 中 | **最优解，见 §1 论证** |
| B. 原版忠实风 | 16×16、原版配色逻辑，只换物品 | ★★★★★ | ★★☆☆☆ | 低 | 最像 MC，但庄严感几乎为零 |
| C. 精细写实方块风 | 高分贴图 + 法线 + 强材质表现 | ★★★☆☆ | ★★★★★ | **高** | 视觉最好，但开始背叛 MC 调性 |
| D. 风格化低多边形 | 突破体素，允许斜面与非正交几何 | ★★☆☆☆ | ★★★☆☆ | 高 | 视觉独特，但"不像 MC 模组" |
| E. 高对比卡通渲染 | 描边、平涂、强轮廓 | ★★☆☆☆ | ★☆☆☆☆ | 中 | 与法环的油画质感严重冲突，**不推荐** |

**切换代价**：从 A 切到 B 只需降分辨率（低）；切到 C 要重做全部贴图（高）；切到 D 要重做全部模型（高）。所以**现在定方向比后面改便宜一个数量级**。

## 7. 反模式清单（这些做了就一定错）

| # | 不要 | 为什么 |
| --- | --- | --- |
| 1 | 真实动态光 | 改区块光照 → chunk 重建 → 帧率崩 |
| 2 | 关键逻辑放自定义 shader | Iris + 光影包下会被静默接管 |
| 3 | 主表现走原版粒子 | 玩家会把粒子调成"最少"，效果直接消失 |
| 4 | 每件装备都发光 | 黄金一旦泛滥就失去意义（见 §2 支柱二） |
| 5 | 混用多种元素主题色 | 60/30/10 里的 30% 必须是**单一**元素 |
| 6 | 敌人跟着武器一起提精度 | 会失去层次对比，且几何预算翻倍 |
| 7 | 为单个技能开第三个 RenderType | 批处理退化，见 VFX 管线规范 §2.3 |
| 8 | 贴图里用大幅渐变 | 与 MC 的明度分层调性冲突，远处会糊 |

## 8. 风格一致性验收

### 8.1 可机检

| # | 检查 |
| --- | --- |
| 1 | 所有资产顶点吸附到 1/16 网格，无超出 |
| 2 | 各类别贴图分辨率符合 §3.1 契约 |
| 3 | 所有颜色取自 §2 色板（容差 ΔE ≤ 3） |
| 4 | 无真实动态光调用；无自定义 shader 承载关键逻辑 |
| 5 | 常驻发光资产占比 ≤ 10% |

### 8.2 必须人看（在目标光照下，不是默认场景）

> 这一条来自标准资产审查流程：**不允许只看 DCC 预览或浏览器预览就通过。** 你们的 `art/skill-fx/preview.html` 很好用，但它不能替代游戏内检查。

| # | 检查 | 不通过的含义 |
| --- | --- | --- |
| 1 | 关闭所有粒子后，战技是否仍可辨认、能否确认命中 | 装饰层和必须层职责搞混了 |
| 2 | 把颜色调成灰度，五把追忆武器能否靠形状区分 | 形状签名没做到位 |
| 3 | 精细武器与粗块敌人同屏，是否出现割裂感 | 密度契约越界 |
| 4 | 在 128 格外看战技，是否还能辨认是哪个技能 | LOD 策略错误 |
| 5 | 装上 Iris + 光影包后，发光是否仍可见 | shader 被接管，信息编码位置错了 |
| 6 | 与 MC 原版方块/怪物同屏，是否显得"不是同一个游戏" | 风格偏离 MC 调性 |

第 2 条和第 5 条是我认为最能暴露问题的两个检查——**一个测形状，一个测环境兼容性**，都是纯靠预览发现不了的。

## 9. 需要你定方向

风格是方向性决策，我不能替你拍板，但我的推荐很明确：

| # | 问题 | 我的推荐 |
| --- | --- | --- |
| 1 | 走哪个方向 | **A. 暗黑奇幻方块风**（§2） |
| 2 | 敌人是否跟着提精度 | **不提**（§4.2，保持层次对比） |
| 3 | 色板是否按 §2 那套走 | **是**，但需要你确认黄金的使用尺度 |

第 3 条是真分歧：**黄金用多少决定了这个 Mod 是"庄严"还是"俗气"**。我给的是 10% 点缀，但法环本体的黄金其实比 10% 多得多——如果你想要更"法环"一点，可以放宽到 15–20%，代价是视觉噪音上升。

确认之后我把这份扩成可下发的资产规范（含逐类资产的色板绑定、粒子配色表、元素编码表），美术可以直接照着做。
