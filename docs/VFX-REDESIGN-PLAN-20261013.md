# 像素特效重做方案

依据：用户认为当前特效难看；继续采用最新的原版 Minecraft 像素风与 2D 序列帧方向。此文件是新一轮计划，不能当成已制作或已验收。

## 当前问题

当前 SkillSlashSpriteRenderer 默认把 explosion_0..15 拉成长条；SkillEffectRenderer 还叠加盒体轮廓。现有水鸟预览出现大量交叉直线，弧形斩击轮廓不清。配色、资源重载与预算框架可以保留，主要问题需要从素材轮廓、朝向和时间节奏解决。

## 顺序

1. 先查现成的斩击、火焰和冲击序列帧；仅从作者来源获取并核对文件许可。不要从法环或 ARR 模组拆取资源。
2. 先做三个样板：水鸟乱舞（短而清晰的银白弧线，按连段逐次出现）；命定之死（黑红弯月主轮廓，短促红焰余迹）；黄金波动（沿地面前进的金色波前，有清晰前沿与渐散尾迹）。
3. 每种效果分为起势、主效果、命中反馈、消散。时间由既有服务端阶段驱动，表现不更改伤害、FP、判定范围和持续时间。
4. 刀光固定在斩击平面；烟雾和小火星才使用面向镜头的粒子。停止把爆炸帧作为正式刀光，不用密集长方体和大范围半透明叠层充当精细程度。
5. 先给用户看三个样板在实际游戏中第一/第三人称的短片，分别覆盖亮处和暗处，再推广至其余追忆战技。静态浏览器图仅用于初选，不代替游戏验收。

## 素材候选（2026-10-13 页面核对）

- Foozle Lucifer Effects：https://foozlecc.itch.io/lucifer-effects 。作者页面标示 CC0、像素特效；待逐项检查动画形态和文件适配，尚未下载或导入。
- Kenney Particle Pack：https://kenney.nl/assets/particle-pack 。80 张 512×512、CC0；仅作小粒子/遮罩候选，不把高分辨率柔光直接当原版像素刀光。
- Henry Software Pixel Effects：https://henrysoftware.itch.io/pixel-effects 。35 种像素动画、PNG、素材 CC0；当前页面下载收费，暂不购买，优先免费候选。

## 分工与交接

用户最新明确要求“特效制作交给美术部门”，替代此前停止美术及将特效素材交给 Harness 的分工。美术部门只恢复本轮特效制作，先完成三个样板的素材、动画预览与交接；装备贴图等旧批次不自动恢复。战斗部门负责渲染接口、资源同步、实机接入与验证；具体代码续写仍可交给用户安排的 DeepSeek Harness。两部门执行入口为 ART-VFX-WORK-ORDER-20261013.md。不自行启动 Harness。

复用 PresentationRoutes、FxPalette、FxGeometryCache 和现有预算。需要明确每个样板的帧数、播放区间、世界朝向、挂点、显示尺寸与淡出曲线，不能让所有技能共用一套爆炸帧后仅换色。具体数值以样板观感确定，避免先硬编码未经验证的整套参数。

验收：轮廓可辨；斩击有明确方向；角色与目标仍清晰；结束不残留；摄像机转动时刀光不跟着乱转；视觉范围与既有判定相称；多人叠加沿用预算降级。通过样板视觉确认后，才视为具备批量替换标准。
