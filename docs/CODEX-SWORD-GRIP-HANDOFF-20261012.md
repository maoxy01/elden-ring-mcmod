# 剑柄几何与握空气问题交接

日期：2026-10-12。对应用户反馈：游戏手掌没有包住剑柄，像握到空气；剑型参考原版钻石剑的像素阶梯轮廓。

最新用户选择：大剑、特大剑使用精修前旧版；直剑保留新版。六个旧版文件已恢复，握区 JSON 已重新导出。接入方同步当前 `art/weapons/` 文件，勿从已撤回的 R4 候选缓存读取这两把剑。

更新：三剑精修 R4 实际模型、网格和 Blockbench 已写入 `art/weapons/`，数据已重新导出。后文“尚未制作”保留为历史记录；当前交付与文件清单见 `ART-DEPARTMENT-REPORT-20261012.md` 的“三剑新版资产”。需要接入方同步后拍游戏手掌与柄部近景。

三类剑的实际柄部数据已经导出到 `art/weapon-proportions/sword-grip-regions.json`。语义区段来自扁平化前名为 `grip` 的立方体；随后在当前运行模型上以 0.25 模型单位间隔检查中心线连续占用，并记录当前横截面。每项带当前模型 SHA256，模型更新后重新导出。

三项的实际几何均包含 `[0,0,0]`，柄部中心也位于实体几何内，可握中心线没有断缝。这个结果说明这三件并非在原点处完全没有剑柄；它不能证明原版显示矩阵变换后的柄部落在手掌里。

坐标约定：16 模型单位 = 1 方块，主轴 +Y，薄片法线 Z；源模型原点保持 `[0,0,0]`。mesh 的 positions 已为方块单位。表中的中心是可用于对齐的候选锚点，不是自动要求把模型原点改过去。

接入侧需按实际调用顺序检查模型点到手掌的最终变换：玩家/手臂、原版 item display、图标中心补偿、逐件倍率、WeaponCorrections。测试柄部中心与可握区段在第一/第三人称、左右手和两种皮肤中的实际位置。缩放候选围绕选定握点进行，保持该点的世界位置；若使用非零柄部中心，对应局部矩阵末端需有 `translate(-handleCenter)`，避免缩放把柄部中心带走。

验收要看手掌包住柄部，柄不会在手指外平行悬浮；还要确认手没有握到护手或柄头。不要用 `grip=[0,0,0]`、网页夹具、只有原点相等的测试替代实机近景。

美术精修方向：原版钻石剑的阶梯收尖、斜向像素外缘、清楚的护手与独立剑柄。直剑保持窄刃，大剑加强肩线与较长握柄，特大剑保留宽厚剪影；锯齿感来自像素阶梯，不添加现实锯条刀齿。此文交付握点资料，新的三剑精修模型尚未制作。

重建数据：`node art/tooling/export-sword-grip-regions.mjs`。本命令只写美术数据，不改游戏显示矩阵。
