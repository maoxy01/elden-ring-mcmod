# 用户提供素材的用途评估

2026-10-16。仅检查与方案，不修改用户原图，不切换正式资源，不启动部门制作或游戏。本方案遵守两部门串行工作规则。

## 最新审阅结论：辨识度优先

用户指出这批缩小图中的多件武器丢失特色，尤其神躯化剑不如项目现有版本醒目。统筹已重新查看1024原图、64图以及项目64手持/16GUI图：原图的细微纹理和刃根结构在64缩图中难以读出，当前自有版本的金色块面与分叉护手更显眼。因此神躯化剑继续采用当前自有设计，不再安排直接替换候选。此结论针对实际尺寸的识别效果，不等于原始1024素材没有细节。

原先“先试八追忆替换、再推广”的选择范围过宽，改为逐件筛选：先明确哪件现有设计确有不足，再看外来素材能否改善。原作来源、分辨率和纹理细节不作为自动优先条件。

每件候选按同样标准比较：隐藏名称后能否区分类别与具体武器；独特剪影、护手/刃根/头部特征在实际16GUI槽位和游戏手持尺寸下是否可见；浅深背景均可辨；不靠统一放大或全图描金制造区别。必要时从原图提炼特征，在当前自有像素设计上局部强化，保留有价值的已有成果。

## 已核对的内容

- 三个武器目录是同一组552张图的三个尺寸版本，不是1656种装备：403武器、81盾牌、68箭矢/弩箭。原图1024×1024，另有32与64版本。
- 说明和转换记录标明32/64使用Lanczos、预乘透明缩小。抽查神躯化剑与义手刀PNG确认有大量半透明像素，不能当作已经按原版像素语言重绘。看过原图与64版总览、单张32/64义手刀。
- 特效目录有564张实际PNG，另有564张预览缩略图，不能把二者合计1128算作独立纹理。564张实际纹理中504为RGBA、60为灰度遮罩。
- 原始定义包括8639份FXR、288份FLVER、18个动画包及64个展开HKX；它们不是Minecraft现成模型/粒子定义或完整战技序列帧。
- 267条战技名称索引明确标记动作事件到FXR尚未逐招定位；214条魔法/祷告参数记录中207条可关联PNG，不等于已还原动画。
- 来源记录为本机ELDEN RING游戏资源提取。提取记录证明来源与转换，不证明随本项目公开分发的授权；当前先保留为本地参考/测试候选，公开发布资源准入另行核实。原始文件继续放dist，不自动纳入GitHub或发布包。

| 输入 | 主要用途 | 使用前处理 |
|---|---|---|
| 1024原图 | 识别武器结构、选色、观察护手/柄细节，作为后续转换母图 | 保留原画布与原文件；派生文件另存，不覆盖 |
| 32图标 | 物品栏、战灰/装备列表等小尺寸显示候选 | 在真实16GUI像素槽位检查；细刃、护手和低对比部分必要时做像素整理 |
| 64图标 | 游戏手持薄片、掉落物/展示框候选，详情页备用 | 校准柄锚点、像素长轴、左右手和朝向，检查透视/预绘光影；不因64图比32图大就放大世界长度 |
| 特效PNG | 经筛选的火焰/烟尘帧、斩击遮罩、符纹及噪声；也可供当前自有特效改进参考 | 区分颜色/alpha/遮罩/法线/模型UV；验证单元格、帧顺序、混合方式与着色再使用 |
| FXR/FLVER/HKX及依赖表 | 定位具体资源与理解层次、运动和时序 | 不直接交给Minecraft加载；只将确有需要的表现参数映射到现有渲染框架，不因此扩展玩法 |

## 先做小批对照，再决定推广

1. 保留当前神躯化剑与已认可的特色武器；从现有设计确有不足的项目中逐件筛选外来图。只有实际辨识度更好的候选才制作同尺寸对照；适合参考而不适合直用的素材只提炼结构与配色，不先全量重画552张。
2. 美术筛一个火焰帧表样板：查清帧格、有效帧、alpha与着色，制作离线播放对照。当前s31041_a可见多格火焰/环形变化，但未据此认定它属于某个追忆战技，也未证明按行顺序就是正确播放顺序。
3. 美术交付结束后，战斗/DSH再接上述小批测试候选；先修当前装备2D已确认的渲染阻断，检验左右手/弓盾状态、亮暗背景和资源重载。
4. 样板观感确认后只推广通过逐件筛选的武器，保留其余自有设计。普通33类依同一标准选代表；特效按现有八技能逐一定位和替换，不从原始库任意选图就宣称还原对应战技。

此路线保留目前原版像素方向，同时允许用实际对照决定用户提供图标是否直接采用。若用户后来明确改为原作图标直用的视觉方向，再调整风格要求。
