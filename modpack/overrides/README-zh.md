# Elden Combat 0.2.0 候选整合包

MC 1.21.1 / NeoForge 21.1.219 / Java 21。纯原版玩家模型与普攻，八个追忆战技由服务端控制。41 件装备模型已接入；视觉比例由美术部门继续验收。Boss 新开发暂停。本包不是完整法环复刻。

导入独立实例：将 EldenCombat-0.2.0-PCL.zip 或 .mrpack 拖入支持 Modrinth 格式的启动器，联网下载固定依赖，选择 Java 21。不要覆盖历史 0.1.0 实例。PCL 实际导入与保存重进尚待验收。

默认按键：R 战斗模式；C 武器战技（追击窗口再按）；G 蓄力；左 Alt 翻滚；X 弹反；V 喝药；鼠标中键锁定。可在控制设置改绑。原版跳跃保留，战技可专用跃起。

依赖：Sodium mc1.21.1-0.6.13、Iris 1.8.12、Entity Culling 1.11.3、Cloth Config 15.0.140、FerriteCore 7.0.3、Lithium 0.15.4、JEI 19.27.0.340，固定哈希见 mods.lock.json。不需要 Epic Fight。Sodium/Iris/Entity Culling 只在客户端；JEI 服务端可选。包不附带光影、测试世界或账号。

试玩：开启作弊新世界，用 /give @s eldencombat:sacred_relic_sword 获取神躯化剑，在平地按 C 施放黄金波动。其余战技和逐件功能验收见战斗回执。不以归档生成证明安装成功。

强化上限：类型武器 +10、追忆 +5；普通石 8 档、失色石 5 档。材料获取和铃珠商店仍待后续成长闭环。

2026-10-13 本地测试候选：新直剑、用户选定旧大剑/旧特大剑；矛/中盾/长弓使用当前精修资产。尺寸和整体质量尚待用户审阅，动态弓弦尚缺美术动作数据，盾背/细臂最新消费路径未完全验收。八技伤害、代表取消、死亡FP与真实保存重载已有开发实例证据；开发实例不是PCL安装实例。候选仅供内容检查，不标正式发布。
