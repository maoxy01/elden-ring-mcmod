# 原版像素 HUD 美术候选

2026-10-23。仅美术素材与可操作预览，未接入游戏，未更新安装包。

## 本次修改

- 按用户参考图保留原版心形血量、护甲、饥饿、经验和快捷栏。
- 蓝条在左，位于护甲上方；蓝条与护甲、护甲与最近一排血量的可见空隙均为 2 GUI 像素。
- 金色耐力在右，恢复到原来氧气所在的位置，不再强行与蓝条同高。
- 耐力和氧气共用右侧同一行：陆地仅耐力，潜水仅原版氧气气泡，蓝条始终保留。
- 去掉条上方的中文标签及当前值/上限，只保留资源条本体。
- 物品名独占上一行，不随本次条位置调整移动。
- 多排生命出现时，左侧蓝条及物品名一起上移避让；右侧耐力/氧气保持在饥饿上方原行。
  潜水切换不改变位置。

## 交付入口

- `preview.html`：本地直接打开；可调数值、切换装备、预设和查看区域。
- `textures/`：16 张硬边像素 PNG；其中 `map_demo.png` 仅用于地图示意。
- `manifest.json`：素材尺寸、哈希和布局参数。
- `qa/eldencombat-hud-v02.png`：默认布局的 1920×1080 透明叠加图，不含场景。
- `qa/hud-overlay-480.png`：480×270 GUI 单位、2 倍采样，即 960×540 PNG。
- `qa/composite-480.png`：同尺寸背景合成，仅为美术预览。
- `qa/hud-closeup.png`：当前底部布局截图。
- `qa/hud-underwater-closeup.png`：同机位潜水布局，右侧只显示气泡。
- `validation.json`：自动检查结果，不代表实机验收。

数值、Boss 名和地图地形均为演示数据。背景取自本项目既有测试截图，
不证明这套 HUD 已在游戏中加载。透明 PNG 是布局审查图，不应把整张图当游戏 HUD 贴图使用。

## 布局合同

以 `preview.js` 的 `calculate()` 为准，坐标单位为缩放后的 GUI 像素。
`W/H` 为 GUI 尺寸，`cx=floor(W/2)`；左右列起点为 `cx-91`、`cx+10`。

| 元素 | 位置及尺寸 |
| --- | --- |
| 原版快捷栏 | y=H-24，182×22 |
| 原版经验条 | y=H-31，182×5 |
| 第一排心形 | y=H-43，每图标 9×9、间隔 8 |
| 护甲 | 心形 y-生命排数×10-1 |
| 气泡 | 原来氧气行 y=第一排心形 y-10，81×9；仅水下显示，替代耐力 |
| 蓝条 | y=护甲 y-9，81×7；与护甲的空隙为 2 |
| 耐力 | 与原来氧气同一起点，y=第一排心形 y-10，81×7；仅非水下显示 |
| 物品名 | y=护甲 y-42，居中，最大宽度 182 |
| Boss | 默认 y=20，182×6；名称 y=7；小画幅时避开地图 |
| 地图框 | 左上 (8,8)，60×60；大 GUI 短画幅缩为 44×44 |
| 状态图标 | 右上，18×18，间距 20 |

默认 480×270 时蓝条 y=207，耐力及氧气行 y=217，
护甲 y=216，物品名 y=174。预览用 2 倍画布保留原版中文字形的半 GUI 像素细节，
不要求游戏固定采用某个物理分辨率。生命排数演示上限为 4，不是服务端限制。

## 给 DSH 的接入说明

1. 复用原版血量、护甲、饥饿、气泡、经验、快捷栏、物品名计时和字体，不重画这套逻辑。
2. 当前 `CombatHud` 用经验条位置显示绿色耐力并隐藏经验；本候选要求恢复原版经验，
   将耐力移至右列金色短条、FP 移至左列蓝色短条。此处尚未修改 Java。
3. 数值沿用 `ClientSkills.fp()/maxFp()`、`ClientCombat.stamina()/maxStamina()`；
   美术调整不得改变蓝耗、耐耗、命中或同步。数据仅驱动填充，不绘制资源名称或数值。
   水下右侧不绘制耐力底图、填充或空耐力警告，保留原来氧气行，只替换显示内容；
   不额外添加氧气数字，不修改真实氧气消耗。出水后恢复耐力，不改动其实际数值。
4. 资源底图先绘制；填充按 clamp(当前值/上限,0,1) 横向裁剪，填充相对底图偏移 (1,1)。
   上限为零时填充为空，比例不得越界。PNG 最近邻采样，禁止柔边缩放。
5. 对接原版 Boss 层，保留其真实名称/进度，不额外叠画第二条 Boss 栏。
6. 小地图接现有地图模组的真实数据与配置；本轮仅制作框和标记，未实现地图后端。
   当前 JourneyMap 入口提示不是已接入的实时小地图。状态图标需绑定真实效果后再显示。
7. 新 HUD 素材独立走 GUI 资源，不加入装备 `routes/2d.json`。先做客户端布局适配，
   再验常规/大 GUI、多排血量、水下、骑乘、Boss、长物品名及其他模组覆盖层。

## 重建与检查

从项目根目录运行；本地原版参考资源缺失时先执行提取脚本：

```powershell
powershell -File art/ui-pixel/hud-v02-20261023/extract-vanilla.ps1
node art/tooling/build-hud-v02-20261023.mjs
node art/tooling/check-hud-v02-20261023.mjs
```

校验覆盖 16 张 PNG、27 组预设/画幅、控件、快捷栏点击、透明导出以及 723 份受保护文件。
未覆盖真实游戏数据接入、多人、光影、骑乘运行画面或用户最终观感验收。
