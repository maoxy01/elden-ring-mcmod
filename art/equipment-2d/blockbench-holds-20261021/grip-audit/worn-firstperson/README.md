# 第一人称拳套 / 钩爪补查

2026-10-21。使用真实 Blockbench 原生离屏视图，统一为 1600×1000、70° 垂直 FOV；未启动游戏，没有修改已准入的模型、贴图或握姿参数。

八个临时工程：拳套/钩爪 × 左右手 × 宽臂/细臂；每个工程保存静止、挥拳（swing=0.35）、装备切换（equip=0.5）三个原生视图，共 24 张。镜头位于原版第一人称物品空间的原点，朝 -Z。

复用当前项目的 Minecraft 1.21.1 源码 `ItemInHandRenderer.renderPlayerArm`，按原顺序应用平移、挥拳旋转和手臂定位；再应用 `PlayerRenderer.renderHand` 的 ModelPart 枢轴及静止 Z 摆动。HumanoidModel.setupAnim 的站立分支把手臂 y 恢复为 2；没有误用细臂建模初始化时的 2.5。手甲采用当前运行导出的同一作者几何，细臂仍使用运行时的 ±0.5 模型单位横向修正，左右没有重复镜像。

原先自动创建的主窗口预览宽高比随界面布局变化，不用于判断 16:10 下的裁切；`qa/*_1600x1000.png` 和 `native-review-1600x1000.json` 才是本次有效回执。

观察：静止时手甲位于下角，手臂根部自然出画；钩爪爪尖在右手视图内，挥拳时向内进入视野；左右姿势对应。没有据此新增第一人称位移，也没有因追求整条手臂可见而让手甲漂浮。

限制：参考手臂为作者提供的中性肤色，不是实际玩家皮肤；没有重放头部晃动、所有挥拳时刻、第三方取消手臂渲染事件或游戏资源重载。这些原生预览只能补充几何与投影证据，不能代替实机加载、所有皮肤及最终观感验收。

入口：`tools/equipment2d/prepare-worn-firstperson.py` 生成临时工程；本目录 `native-review.js` 在 Blockbench 原生视图回放。离屏视图由 Blockbench MCP 创建；不会自建替代渲染器。运行前应确保 `native-review-1600x1000.json` 已存在，避免读取不存在文件的原生回调无法结束。
