# 单刃朝外修正 2026-10-20

人类明确：附件原版钻石剑只作参考，修项目自己的武器；有几把刀口朝向自己。

本轮核对已准入的曲剑、曲大剑、义手刀、咒剑和黑剑贴图，明确其握柄至刀尖轴及下/右侧刃口。仅改第一人称左右手Display，共检查10组、实际修改9组。黑剑右手原本朝外，原样保留。双刃大剑、原版、第三方模型、其他装备及第三人称不作批量翻转。

复用从当前Minecraft 1.21.1资源与ItemTransform取得的显示矩阵。绕握柄至刀尖的长轴转动，保持两端、正缩放、武器长度和握点不动；刀口既朝持剑手外侧，又带远离玩家的分量。左右手独立计算，没有修改或镜像PNG，也没有把刀尖掉头。第一轮数学预览发现只查世界轴会使左手接近侧对镜头，已弃用；最终解额外检查视线与刃面夹角，避免变成一条细线。

- `verification.json`：10组前后参数、轴向旋转量、刃口方向、刃面投影、握柄/刀尖误差。最大误差小于1e-8格。
- 五份`.bbmodel`：可直接在Blockbench打开；沿用原生工程，只写入本轮Display参数。几何、纹理、其余显示槽和原历史保持不动。本轮不是经Blockbench原生UI保存和截图的验收。
- `comparison-all.png`：左起右手旧/新、左手旧/新；五行分别曲大剑、曲剑、义手刀、黑剑、咒剑。
- `routes-before.json`与`overrides-before.json`：回退及重跑基线；工具不会累计旋转。
- 生成工具：`tools/equipment2d/correct-cutting-edge.py`；预览工具：同目录`preview.py`。

预览是静止70度手部投影示意，不是Minecraft截图。朝向的参数检查不等于实际挥击、第三人称、光影和用户观感已通过。本轮不合入先前的大小/位置候选；那个候选的来源哈希现已过期，不能直接覆盖此修正。
