# 抓钩 / 拳套：穿戴式手甲（Worn Hand Gear）契约

2026-10-21 · Blockbench 5.2.2 原生保存 · 由 `art/equipment-2d/worn-hand-gear-20261021/` 提供

## 1. 做了什么

抓钩（钩爪）与拳套从"握在手里的武器"改成**绑在双手上的手甲**：

| 物件 | 形态 | 结构 |
|---|---|---|
| 抓钩 `claw_worn.bbmodel` | 手背木板 + 钢箍 + 3 根弯钩爪 + 掌/腕皮扣 | 木背板 4 片、2 道钢箍（带铜铆钉）、指节护板、3 根 5 段旋转爪（根宽 1.05 收尖 0.22）、2 道掌带 + 腕带 |
| 拳套 `fist_worn.bbmodel` | **方形铁锤头** + 喇叭护腕 | 7.5×7.5×7.5 立方体锤头、正面加强板、上下盖沿、4 条角包边、赤道铁箍（4 颗黄铜铆钉）、正面 2 颗铜钉、4 段喇叭护腕、前臂皮带 |

全部是立方体（拳套**没有** mesh 球），方块数：抓钩 104（导出 94）、拳套 66（导出 56）。
两只手各一份几何，左手指的是右手几何关于 x=0 的镜像，运行时**不需要再做左右翻转**。

## 2. 坐标与挂点（代码需要照这个接）

- 单位：1 unit = 1/16 格（`units_per_block = 16`）。
- 空间：MC 玩家模型**静止姿态**；+y 向上、模型正面 -z、玩家右侧 -x。
- 参考尺寸：头 24..32、躯干 12..24、腿 0..12、手臂 y 12..24（x 右 -8..-4 / 左 4..8）、手 = 手臂最下 4 格（y 12..16）。
- 手臂枢轴：右 `(-5, 22, 0)`，左 `(5, 22, 0)`——两个 `arm_right* / arm_right_l` 组的 **origin 就是枢轴**。
- 下发方式：先平移手臂枢轴、再套手臂段骨骼矩阵；等价于把整个组挂在 `arm_R` / `arm_L` 上。
- 已量：抓钩包围盒 `x[-9.44,9.44] y[5.32,17.8] z[-2.38,2.3]`（两只手合计），拳套 `x[-10.01,10.01] y[10.19,23.2] z[-4.17,4.01]`。

## 3. 组结构

```
<物品> | 名称
├─ arm_right   origin (-5,22,0)       ← 导出
├─ arm_right_l origin ( 5,22,0)       ← 导出（镜像副本）
└─ ref_player  (export=false)         ← 仅 Blockbench 里看比例用的假人，不导出
   ├─ ref_head / ref_body / ref_leg* / ref_shoe*
   ├─ ref_arm_right  origin (-5,22,0)
   └─ ref_arm_left   origin ( 5,22,0)
```

参考假人所有方块 `export=false`，任何导出/转换都应跳过；真正要渲染的只有 `arm_right` 与 `arm_right_l`。

## 4. 素材

- 贴图：`textures/worn_atlas.png`，128×128 单图集、逐面 UV、1 texel = 1/16 格（与 MC 原生长度一致），材质分格（铁、锈、钢、木、皮革、黄铜、皮肤/衣服仅供假人用）。
- 图标：`icons/<id>_gui_16.png`、`icons/<id>_gui_32.png`（16 是原生尺寸，32 为高清，均由模型 64px 正交渲染收边而来）。
- 预览：`qa/`（正面/3-4/手背或外侧/出拳侧视/出拳正面/半抬姿势），`qa_worn_sheet.png` 是 6 格总览。

## 5. 已知的管线缺口（本次没有强改）

1. 现有 `gradle/equipment-2d.gradle` 只接受 **42 条 `own_sprite`** 路由，逐条要求 16/32 精灵与厚度模型；把穿戴件塞进去会直接构建失败。所以要新开一条 `worn` 路由（或独立注册为手部装备），不要复用 `own_sprite`。
2. 渲染要挂到玩家手臂段：`PlayerModelPoseMixin` 已有玩家骨骼，建议加一个渲染层：取 `arm_R`/`arm_L` 的段矩阵 → 平移到枢轴 → 画 `arm_right`/`arm_right_l` 的立方体。
3. 旧的手持条目（`blockbench-all-items-20261018/items/claw.bbmodel`、`fist.bbmodel` 及 6 张手绘状态图）**没有删**，等穿戴渲染落地后再切换，避免现在把 42 条路由打断。

## 6. 校验

- 两个工程都能被 Blockbench 原生 codec 重新载入：抓钩 104 立方体 / 6 组 / 1 贴图；拳套 66 立方体 / 6 组 / 1 贴图（无 mesh）。
- 参考假人 10 件全部 `export=false`，导出面只含手甲。
- 左右手几何逐块对应（镜像后 `x` 取反、绕 z 旋转取反），没有共用错误。
- 所有渲染来自 Blockbench 场景（自建 WebGLRenderer + 固定相机），不是网页假 3D；相机与假人比例同图可查。
