# 追忆武器首批资产

2026-10-11。Codex 负责建模，游戏代码由用户安排的其他 agent 接续。

本批为 8 件本体追忆武器的自制 MC 风格精细化第二版，不是全部追忆装备，也不包含 DLC。没有提取或打包原游戏模型与贴图。

## 查看与编辑

打开 `preview.html` 查看总览、单件和精选视图；单件可切换柄部、刃体近看，支持旋转、缩放与平移。原先 `art/weapons/preview.html` 顶部也有“追忆武器”入口。

每件有 `.bbmodel` 和 `.model.json`，共用原创 `weapons.png`。图集重新生成为 **2048 x 2048 RGBA**，16 个材质区各 512 像素；逐面像素密度从 3.5 提升为 7 像素/单位，线性密度 2 倍、像素面积 4 倍。不是对上一版 PNG 做插值放大。

模型添加五层刀刃倒角、五条带构成的圆角截面、细分球面、螺旋缠柄、雕花浮雕、指节、血管、铆钉和微裂纹。细化目标是每件至少上一版 4 倍几何量，实际数量见表与 `validation.json`；几何数量不等同于视觉质量或游戏性能。

Blockbench 使用 free 格式，内嵌图集。游戏模型使用原项目方块骨架格式的扩展字段 `faceUVs`，不能直接当作原版物品模型 JSON 或 Epic Fight 玩家动画。

### 审查修正

针对五处浏览器标注，补齐黑剑、亵渎圣剑、碎星大剑、蒙葛特咒剑的贯穿剑茎与护手套口，刃根和柄端实体重叠接合，不再悬空拼装。蒙葛特咒剑尾钮也向柄内收紧。

针对后续“连接处还是不合理”的反馈，进一步把四把剑的刃根下移至护手内部，收成宽肩并嵌入宽护手座，缩短外露接头；不再只靠细柱连接。这是造型修订第三次导出，不是增加关节。柄部近看已重新截图，采样连通仅为最低检查，最终外观仍由用户审查。

神躯化剑改为一条连续刃芯，双股扭纹在高度 20 至 34 之间逐渐收拢、变细并融入刃芯；移除旧独立直刃剑尖。截面宽度、厚度和脊线连续收尖，不在原接头处突然变宽。

新增 `weapon-structure.mjs` 与模型中的美术检查元数据 `structuralChecks`、`profileChecks`。按实际 XYZ 旋转后的实体检测柄端至刃根的五条轴向采样线，神躯化剑额外检测扭纹至剑尖的实心刃芯和截面包络变化。检查复现了旧版四处断缝与旧神躯化剑截面突变；删除连接几何的负向回归也必须失败。有限采样不是所有装饰的全局拓扑证明。

## 再生成

在 `art` 目录使用已安装的 package.json 工具依赖：

```powershell
npm run build:remembrance
node tooling/verify-weapons.cjs <含 playwright 与 pngjs 的依赖目录> --remembrance
```

模型源：`art/tooling/remembrance.mjs`；图集、UV 与 BB 导出：`art/tooling/build-weapons.mjs`。在 BB 中修改后，应回写源定义，否则再次生成会覆盖它。

外观参考链接在 `references.json`。Three.js 用于预览，许可证见 `THREE-LICENSE.txt`。
