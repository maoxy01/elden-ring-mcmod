# 武器尺寸候选

这是“武器看起来偏小”反馈的独立试排。具体武器和预览/实机场景尚未确认，当前 targets.json、profiles.json、原比例预览均未覆盖。

打开本目录 `preview.html`，选择匕首、直剑、特大剑、长矛、中盾或神躯化剑。每件均有当前、+15%、+30% 三个候选，人物高度统一 1.8 格；同一视口下镜头、照明和人物像素高度一致。只改变武器以主握点为中心的等比倍率，长短关系保留。

对照模式将武器底端放在同一基线上。握点模式固定主握点，尺寸变化不会把握点一起移动。它是离线美术夹具，不复现游戏 ItemRenderer。

这些增幅是审阅候选，不是原作实测比例，也不是用户已选定的修改。基线的 40 件待参考校准状态仍然保留。

当前排查：离线场景使用正交镜头，无透视缩短，人物高度由实际几何测得；六件均以静止本地 Y 跨度为主要尺寸。初始源码曾有 0.85/h 等长适配；并行开发后的最新源码已使用 heldScale，但运行实例是否加载最新版本尚未取证。候选基于原美术草案，不能直接等同于当前游戏显示尺寸。

统筹后续已转来明确反馈：所有武器在游戏手持画面偏小，普通装备质量不足。正式尺寸需检查游戏完整缩放链；六件普通装备精修另见 `docs/WEAPON-SIZE-AND-QUALITY-REVISION-20261012.md`。本目录只交付尺寸候选，不表示新模型已制作或实机已验收。

`candidates.json` 记录每项具体倍率和原文件哈希；`validation.json` 记录检查和截图。六张单武器 PNG 适合直接展示三档对照。`sacred-grip.png` 展示同握点候选，`sacred-mobile.png` 是手机布局。

生成与检查：`node art/tooling/build-weapon-size-review.mjs --browser`。
